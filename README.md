JSX is a way to write HTML inside JavaScript. We use it to make the website UI in React.
Props are data passed from a parent to a child. State is data that can change inside a component.
useState is used to store and update data. We used it to store selected technologies in the stack.
useEffect runs code after the component loads. We use it to fetch JSON data.
A unique key helps React identify each item in a list and update it correctly.
Conditional rendering means showing something when a condition is true. We used it to show the empty stack message when no technology is selected.
A parent sends data to a child using props. A child sends data back by calling a function from the parent
